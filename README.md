# Stoffbergie GitHub Defaults

This repository powers the public GitHub organization profile and shared community defaults for Stoffbergie repositories.

## Files

- `profile/README.md` is the organization profile shown on GitHub.
- `.github/ISSUE_TEMPLATE/` contains default issue forms.
- `.github/pull_request_template.md` is the default pull request template.
- `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, and `CODE_OF_CONDUCT.md` are inherited by repositories that do not define their own versions.
